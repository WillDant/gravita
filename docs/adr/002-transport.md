# 002 — UI ↔ engine over a local WebSocket (JSON-RPC 2.0)

Status: accepted

## Decision
The webview talks to the engine directly over `ws://127.0.0.1:<random port>/ws`, JSON-RPC 2.0 (`packages/protocol/src/rpc.ts`). Tauri IPC is used only for native features and to hand the webview the engine's port and token (`engine_info`).

Security: bind to 127.0.0.1 only; a 256-bit token generated by the shell and passed to the engine over stdin; Host and Origin allowlists (DNS rebinding, cross-site); the first frame must authenticate within 2 s; the webview gets no shell or filesystem capabilities and renders untrusted text without HTML.

## Consequences
`pnpm dev` runs the whole UI in a normal browser against the engine (or its demo mode) with no Rust toolchain, which keeps contribution and end-to-end testing simple. A future CLI or remote client can reuse the same API.
